# Playground

Explore complete modal flows against the current workspace source. Start with
the visual lab, then edit the focused example below.

<ModalLab />

## Edit the flow

The editor runs the same library source as the configurator. Change the
contract, component, policy, or open options and see the result immediately.

```tsx playground direction=vertical
import { useState } from 'react';
import {
  createModalSystem,
  defineModal,
  ModalProvider,
  motionPresets,
} from 'react-motion-modal';

function ConfirmDialog({ input, resolve, cancel }) {
  return (
    <section
      style={{
        width: 'min(28rem, calc(100vw - 2rem))',
        padding: '1.5rem',
        border: '1px solid rgb(255 255 255 / 16%)',
        borderRadius: '1rem',
        background: '#2f2f3e',
        color: '#fff',
        boxShadow: '0 1.5rem 4rem rgb(0 0 0 / 35%)',
      }}
    >
      <p
        style={{
          margin: '0 0 0.35rem',
          color: '#8b9af7',
          fontSize: '0.75rem',
          fontWeight: 800,
          letterSpacing: '0.08em',
          textTransform: 'uppercase',
        }}
      >
        Awaitable outcome
      </p>
      <h2 style={{ margin: '0 0 0.65rem', fontSize: '1.35rem' }}>
        {input.title}
      </h2>
      <p style={{ margin: 0, color: '#aaaab4', lineHeight: 1.6 }}>
        The caller receives a typed resolved or cancelled outcome.
      </p>
      <div
        style={{
          display: 'flex',
          justifyContent: 'flex-end',
          gap: '0.75rem',
          marginTop: '1.5rem',
        }}
      >
        <button
          type="button"
          onClick={() => cancel()}
          style={{
            padding: '0.65rem 1rem',
            border: '1px solid #606071',
            borderRadius: '0.65rem',
            background: 'transparent',
            color: '#d2d2d2',
            cursor: 'pointer',
          }}
        >
          Cancel
        </button>
        <button
          type="button"
          onClick={() => resolve(true)}
          style={{
            padding: '0.65rem 1rem',
            border: 0,
            borderRadius: '0.65rem',
            background: '#677cf4',
            color: '#fff',
            fontWeight: 700,
            cursor: 'pointer',
          }}
        >
          Confirm
        </button>
      </div>
    </section>
  );
}

const confirm = defineModal({
  component: ConfirmDialog,
  preset: motionPresets.dialog(),
  policy: 'singleton',
});

const modals = createModalSystem({ confirm });

export default function Demo() {
  const [result, setResult] = useState('No outcome yet');

  async function openConfirm() {
    setResult('Waiting for your choice…');

    const outcome = await modals.open('confirm', {
      title: 'Ship this modal flow?',
    });

    setResult(
      outcome.status === 'resolved'
        ? `Resolved: ${outcome.value}`
        : `Cancelled: ${outcome.reason}`,
    );
  }

  return (
    <main
      style={{
        display: 'grid',
        placeItems: 'center',
        gap: '1rem',
        minHeight: '22rem',
        padding: '2rem',
        background:
          'radial-gradient(circle at 50% 0%, rgb(103 124 244 / 22%), transparent 15rem), #272738',
        color: '#d2d2d2',
      }}
    >
      <button
        type="button"
        onClick={openConfirm}
        style={{
          padding: '0.8rem 1.15rem',
          border: 0,
          borderRadius: '0.7rem',
          background: '#677cf4',
          color: '#fff',
          fontWeight: 800,
          cursor: 'pointer',
          boxShadow: '0 0 1.5rem rgb(103 124 244 / 35%)',
        }}
      >
        Open confirm modal
      </button>
      <output style={{ color: '#aaaab4', fontFamily: 'monospace' }}>
        {result}
      </output>
      <ModalProvider
        system={modals}
        defaultOptions={{
          blur: true,
          backdrop: {
            style: { backgroundColor: 'rgb(0 0 0 / 52%)' },
          },
        }}
      />
    </main>
  );
}
```

The editor is intentionally permissive so you can explore the runtime API.
Your application still gets complete TypeScript inference from its modal
registry.
